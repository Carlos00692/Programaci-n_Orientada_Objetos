## Negocio
Cibercafé — local que renta computadoras por hora e imprime documentos.

## Problema que resuelve
Llevar el control de clientes, computadoras disponibles, tiempo de uso
y pagos de forma manual genera errores. Este sistema modela esas
entidades como clases para organizar esa información.

## CRUD 1: Cliente
- Crear cliente (registrar_cliente)
- Leer/mostrar datos del cliente
...

## CRUD 2: Sesion
- Crear sesión (iniciar_sesion)
- Actualizar (sumar_tiempo)
- Cerrar (finalizar_sesion, realizar_pago)
